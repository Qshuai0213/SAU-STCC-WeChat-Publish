# SAU 创意IT俱乐部 排版风格参考

## 设计哲学

**「干净的蓝」**——我们不是做一张海报，而是让读者舒服地读完一篇文章。

好的排版是**看不见的**。等读者注意到"哇这排版真好看"的时候，已经说明设计开始喧宾夺主了。

```
好设计 = 读者看完说"内容不错" → 而不是"排版不错"
```

每加一个装饰前问自己：**去掉它阅读体验会变差吗？** 不会就去掉。

---

## 配色感觉

蓝色科技感，清爽干净。具体用哪几个蓝色由 AI 在生成时根据文章气质决定。

- 主色选一个沉稳的蓝（深蓝/靛蓝/钴蓝都可以）
- 辅助色可以用稍亮一点的蓝色
- 卡片底色用接近蓝色的浅色
- 文字：正文深灰、辅助文字中灰、标题接近黑色

> 没有固定色值，保持 **蓝** + **灰** + **白** 的主调即可。

常见搭配参考（仅示意，不强制）：
- 主色 → 一个深蓝
- 辅助 → 一个亮蓝
- 背景淡色 → 蓝调和的白/灰
- 文字 → 深灰到黑

## 排版节奏

好的文章像一首歌，有起承转合。排版节奏控制：

```
标题        →  重（大字、居中或靠左）
┊
段落        →  轻（缩进 2em，行高 1.8-1.9）
┊
--------    →  停顿（分割线 / 留白）
┊
小标题      →  拾起（蓝色 pill 或左竖条）
┊
段落        →  轻
┊
信息卡片    →  强调（浅蓝底、圆角）
┊
--------    →  停顿
┊
落款        →  收（蓝色边框卡片）
```

### 字号层级

```
标题        20-22px  粗体
章节标题    16-18px  粗体 + 蓝色
正文        15px     常规，行高 1.8-1.9
辅助文字    13-14px  灰色
```

## 常用组件

所有组件的原则：**一个元素只做一件事**。

### 1. 章节 Pill 标签

适用场景：通知、公告、多段落分节

```html
<section style="display:flex; align-items:center; margin-bottom:10px;">
  <span style="display:inline-block; background:#175ADF; color:#fff;
         font-size:13px; font-weight:bold; padding:2px 10px;
         border-radius:3px; margin-right:8px;">一</span>
  <span style="font-size:16px; font-weight:bold; color:#175ADF;">竞赛简介</span>
</section>
```

效果：数字小蓝块 + 蓝色粗体标题 → 干净利落分清各部分

### 2. 信息卡片

适用场景：联系方式、时间地点、关键信息

```html
<section style="background:#f0f6ff; border-radius:8px; padding:15px; margin-top:8px;">
  <!-- 内容 -->
</section>
```

- 浅蓝底，圆角，不花哨
- 只有背景+圆角，没有投影/渐变/边框

### 3. 分割线

极细分割线，温和地分隔段落：

```html
<section style="width:60px; height:2px; background:#3696EB; margin:20px auto;"></section>
```

- 短、细、蓝
- 不要长线、虚点线、图标分割线

### 4. 章节左竖条

可选替代 pill 标签，更轻量：

```html
<section style="border-left:3px solid #175ADF; padding-left:12px; margin-bottom:12px;">
  <span style="font-size:16px; font-weight:bold; color:#175ADF;">章节标题</span>
</section>
```

### 5. 落款卡片

```html
<section style="width:90%; background:rgba(255,255,255,0.67);
       border:1.8px solid #175ADF; border-radius:12px; padding:15px;">
  <p style="font-size:14px; color:#333; text-align:center; ...">图文 | 创意IT俱乐部</p>
  <p style="font-size:14px; color:#333; text-align:center; ...">排版 | 曲佳明</p>
  <!-- ... 初审/复审/终审 ... -->
</section>
```

- 蓝边框圆角卡片
- 文字居中，留白舒适
- 颜色可随文章色系微调

## 排版决策指南

按这个顺序判断，少纠结：

```
1. 这篇文章是什么体裁？
   → 通知/公告：pill 章节 + 卡片 + 分割线
   → 活动总结：大标题 + 留白 + 少量蓝色点缀
   → 知识科普：自由设计，但保持一层嵌套以内
   → 获奖公示：列表化 + 干净

2. 内容量多少？
   → 短（<500字）：可以多一点设计感，标题大一点
   → 长（>1000字）：减少装饰，让阅读节奏快一点

3. 是否需要强调某个信息？
   → 是 → 用信息卡片
   → 否 → 用分割线或留白分隔
```

---

## ❌ 不要做

- 两个以上元素嵌套（如里面套卡片再套tab再套按钮）
- 三个或以上颜色（蓝色系选1-2个就够了）
- 阴影/投影（微信编辑器渲染不稳定）
- 每一段都用不同样式（保持统一）
- 不同字体混排
- 图标/emoji 做装饰
- 标题区搞得太花哨（渐变背景、大图、蒙层）
- 花哨的边框（点线双线彩色都不行）

## 文档图片处理规则

如果用户提供的文档中有图片：

1. 用 `python-docx` 库解压 `word/media/` 提取图片
2. 转为 base64 字符串，`<img src="data:image/png;base64,...">` 内嵌
3. 通过文档内关系 ID（rId）定位图片在正文中的位置
4. 图片宽度默认 100%，二维码等小图设 `width:180px`
